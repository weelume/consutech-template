# ConsuTech 模板入口

这是可独立运行的 Next.js / React / TypeScript 网站工程，使用 framer-motion 和 CSS 实现原站分区动画，不依赖服务端业务接口。读取资料不会安装依赖、运行服务或发送信息。

先读 `template.json` 的页面与市场信息、`project.json` 的命令与服务合同，再读 `docs/ARCHITECTURE.md`、`CUSTOMIZATION.md`、`MOTION.md`、`VERIFICATION.md` 和 `LICENSE.md`。

环境、安装、启动、端口与停止方式见根 README。默认中文，英文 `/en`。首页原始参考为单页，其他页面为同风格补齐；内容明确为演示。

演示不收款，不发送或保存联系信息，不接入统计服务。素材、视频与字体均在 `public/templates/consutech/`。不得将素材可下载等同于商业许可。截图保存在 `assets/`，仅真实浏览器截图可用作验收证据。
