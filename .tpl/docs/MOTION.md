# 原站动效清单与实现

依据公开预览组件：HeaderSection、Impact、Services、Approach、Result、FAQs、CTA、Footer。参考入口见 LICENSE.md。原站仅单页，新增内页使用相同公共组件与节奏。

| 区块 | 原站触发、运动与参数 | 当前实现 |
| --- | --- | --- |
| 背景视频 | muted/loop/playsInline，播放速率 0.4，亮度 0.6、透明度 0.8 | 本地原视频，保持速率；增加显式暂停与失败提示 |
| 首屏 | 左 x=-80、右 x=80，1s，ease=[.16,1,.3,1]，视口10%，once | 独立两侧入场 |
| 标题 | y=30、blur4，0.8s，第二行延迟0.1s，视口10% | 逐行入场，中英文字号按模板规范调整 |
| 按钮文字 | 双层逐字 y=0到100%/-100%到0，0.4s，每字0.02s | RollingText，悬停并保留按压缩放 |
| 跑马灯 | 三份内容，55s linear，位移-33.3333%，hover暂停；文字scale.9/y15，0.6s | 同参数；另加键盘可用暂停按钮 |
| 影响力文字 | 视口-100px，逐字符y30%/opacity，0.35s，间隔0.012s | 原文英字符按序，中文按字符进入 |
| 数字 | 0到12%，2s线性，首次进入后完成 | 独立 RAF、离开不重置，卸载清理 |
| 图片揭幕 | 4×4，opacity1到0、scale1到.8，0.8s；延迟.2+列*.1+行*.08+确定性偏移 | 16格原参数，不用单一淡入代替 |
| 图表 | 38/55/79/100%，0.8s，间隔.2s；高光y100%到-100%，2.5s循环、间隔.3s | 同参数 |
| 评价 | 5s自动推进，正文x20到0到-20、0.4s；作者y10、0.3s | 正文及作者分层切换，按钮手选；增加显式暂停 |
| 服务 | 初始第1项，hover/点击选中，背景文字0.7s；两侧x±120、1s；图片scale1.25/rotate-3到1/0、0.8s；退出rotate3 | 保留独立参数，增加键盘选择；手机隐藏预览图，平板双栏 |
| 方法 | 300vh容器，sticky100vh；scroll start-start到end-end；spring damping25/stiffness120/mass.5；卡片位移为内容与容器高度差 | ResizeObserver测量，保持滚动映射；四个图标15s旋转 |
| 流程 | 6s每项，进度为(active+当前周期)/3；height0到auto、opacity，0.4s | 同参数及手动选择；增加暂停 |
| FAQ | 左x-60/blur4，右x80/blur4，0.8s、间隔.08；height0到auto、0.35s；加号旋转与缩放 | 按钮可键盘展开，ARIA展开状态 |
| CTA | 文案y40/blur4，1.2s、错峰.15；图片x80/100/120，1.6/1.8/2s、scale.95 | 独立位移及图片scale |
| 页脚 | 邮箱y30/blur4、0.8s；字标y100%到0、1.2s、延迟.5 | 邮箱与自身品牌字标，中文化字号调整 |

响应式：PC1440×1000、平板834×1180、手机390×844，补测320px。手机保留300vh卡片映射，缩小卡片与文案；减少动态效果模式取消循环和滚动绑定，全部卡片自然排布，视频等待主动播放。

差异：按模板规范移除装饰箭头、中文化、字体、玻璃卡片与字号；导航改为真实内页。原站部分按钮与页脚为无目的占位，当前链接接入补齐页面。原站存在文字截断与手机固定字号问题，当前内容完整显示。

验收状态见 VERIFICATION.md。参数匹配和静态截图不等于三端逐帧验收；未完成的实际触发对照必须明确记录。
